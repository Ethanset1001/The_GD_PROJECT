# The_GD_PROJECT
This code is used in 3.13 Python

Note you must run pip install gmdkit in the command prompt to actually decode the gmd file


# HOW TO GET THE LEVEL
You must get Geode ( official link is https://geode-sdk.org/ )
and download the GDShare mod. https://geode-sdk.org/mods/hjfod.gdshare

Then go to a level and click the file icon to download it

# HOW TO SETUP

Move the .GMD file to a file with the python code
Name the gmd file *level.gmd*
and run the python script.

# HOW TO PLAY

Space to jump. thats it really lol
